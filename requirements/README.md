# Reproducible Development Constraints

`pyproject.toml` remains the source of broad end-user requirements. The files
in this directory are generated, fully resolved environments for BO Forge CI
and release preparation.

## Supported constraint sets

| File | Intended environment |
| --- | --- |
| `constraints-py311-linux-x86_64.txt` | CPython 3.11, Linux x86_64, CPU-only PyTorch |
| `constraints-py312-linux-x86_64.txt` | CPython 3.12, Linux x86_64, CPU-only PyTorch |
| `constraints-py312-macos-x86_64.txt` | CPython 3.12, macOS x86_64 |
| `constraints-py312-macos-arm64.txt` | CPython 3.12, macOS Apple Silicon |

Linux is the required full-suite matrix for both supported Python versions.
macOS 3.12 is the economical path/locking matrix; both macOS architectures are
resolved so maintainers and hosted runners select wheels honestly.

All files are generated by `uv 0.11.3` from all `pyproject.toml` extras and
include distribution hashes. The Linux files use the CPU PyTorch index through
`--torch-backend cpu`; no CUDA execution is required by CI.

## Clean bootstrap

Choose the file matching the interpreter and platform. For example, on Linux
with Python 3.12:

```bash
python3.12 -m venv /tmp/bo-forge-dev
/tmp/bo-forge-dev/bin/python -m pip install "uv==0.11.3"
/tmp/bo-forge-dev/bin/uv pip install \
  --python /tmp/bo-forge-dev/bin/python \
  --require-hashes --torch-backend cpu \
  -r requirements/constraints-py312-linux-x86_64.txt
/tmp/bo-forge-dev/bin/uv pip install \
  --python /tmp/bo-forge-dev/bin/python \
  --no-deps --no-build-isolation -e .
/tmp/bo-forge-dev/bin/python -m pip check
```

On macOS, omit `--torch-backend cpu` and choose the file matching `uname -m`.
The project install is deliberately separate and dependency-free: the hashed
file establishes the environment first, then the local checkout is installed
without changing that resolution.

## Regeneration

Run these commands from the repository root with `uv 0.11.3`:

```bash
uv pip compile pyproject.toml --all-extras --python-version 3.11 \
  --python-platform x86_64-manylinux_2_28 --torch-backend cpu \
  --generate-hashes --no-emit-package bo-forge \
  --custom-compile-command "uv==0.11.3 pip compile pyproject.toml --all-extras --python-version 3.11 --python-platform x86_64-manylinux_2_28 --torch-backend cpu --generate-hashes --no-emit-package bo-forge --output-file requirements/constraints-py311-linux-x86_64.txt" \
  --output-file requirements/constraints-py311-linux-x86_64.txt

uv pip compile pyproject.toml --all-extras --python-version 3.12 \
  --python-platform x86_64-manylinux_2_28 --torch-backend cpu \
  --generate-hashes --no-emit-package bo-forge \
  --custom-compile-command "uv==0.11.3 pip compile pyproject.toml --all-extras --python-version 3.12 --python-platform x86_64-manylinux_2_28 --torch-backend cpu --generate-hashes --no-emit-package bo-forge --output-file requirements/constraints-py312-linux-x86_64.txt" \
  --output-file requirements/constraints-py312-linux-x86_64.txt

uv pip compile pyproject.toml --all-extras --python-version 3.12 \
  --python-platform x86_64-apple-darwin --generate-hashes \
  --no-emit-package bo-forge \
  --custom-compile-command "uv==0.11.3 pip compile pyproject.toml --all-extras --python-version 3.12 --python-platform x86_64-apple-darwin --generate-hashes --no-emit-package bo-forge --output-file requirements/constraints-py312-macos-x86_64.txt" \
  --output-file requirements/constraints-py312-macos-x86_64.txt

uv pip compile pyproject.toml --all-extras --python-version 3.12 \
  --python-platform aarch64-apple-darwin --generate-hashes \
  --no-emit-package bo-forge \
  --custom-compile-command "uv==0.11.3 pip compile pyproject.toml --all-extras --python-version 3.12 --python-platform aarch64-apple-darwin --generate-hashes --no-emit-package bo-forge --output-file requirements/constraints-py312-macos-arm64.txt" \
  --output-file requirements/constraints-py312-macos-arm64.txt
```

The generated header records the exact command. After regeneration, review the
package changes, bootstrap an empty environment, run `pip check`, Ruff, the
full test suite, package build, Twine check, and external artifact probes. CI
also checks the files' generated/hash contract. Never edit resolved package
lines by hand.
